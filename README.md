# Avalonia Lab 1 — Часть 1: Кнопки смены цвета окна

Лабораторная работа №1 (часть 1) по курсу **«Структуры данных и алгоритмы»** (направление «Программная инженерия», СГУ им. Н. Г. Чернышевского).

**Группа:** 351  
**Технологии:** C# · Avalonia UI · .NET 10  
**Среда разработки:** Visual Studio Code (расширения C# Dev Kit и Avalonia)

## Задание

Разместить в окне четыре кнопки с надписями «Красный», «Зелёный», «Синий», «Жёлтый». По клику на кнопку менять цвет фона окна (`this.Background`) в соответствии с надписью на кнопке.

Изменение свойств выполняется **в коде** `MainWindow.axaml.cs`. События связываются через атрибут XAML `Click="OnColorButtonClick"`.

## Что реализовано

- Четыре кнопки с заданными надписями
- Общий обработчик события `Click` для всех кнопок
- Определение цвета по имени кнопки через `switch`
- Изменение фона окна через `this.Background`
- Подсветка активной кнопки (тёмный фон, белый текст)
- Сброс стилей остальных кнопок в базовый вид (светло-серый фон, чёрный текст)

## 🛠️ Как запустить

Требуется установленный **.NET 10 SDK**.

```bash
git clone https://github.com/Lynastra/Avalonia_Lab1.git
cd Avalonia_Lab1
dotnet run
```

## Небольшие трудности

**1. `Unable to find suitable setter or adder for property Click`**

Ошибка возникает при указании `Click="..."` в XAML, если сборка проекта устарела. Решение:

```bash
dotnet clean && dotnet build
```

Если не помогло — перезапустить VS Code. Проблема в кэше IDE, не в коде.

**2. `Name cannot begin with the '<' character` в `Title`**

XML-парсер Avalonia не принимает символ `№` в атрибутах напрямую. Решение: не использовать `№` в XAML, заменить на `N` или `#`, или вообще не использовать данный символ, если есть такая возможность.
